蓝冰

同样的文字，蓝冰让层级更轻。这一套主题只做三个动作：冷调的底、磨砂的面、克制的暖色，其余全部交给字距与留白。

正文里偶尔需要一点强调 —— 比如 这样一条琥珀纸带，或者按下 ⌘ + K 唤出快捷面板，也可以用 inline code 标注一个小片段，剩下的交给 链接 与 被划掉的旧结论。

冷调画布

底色不能是纯白。纯白太硬，雾面会失去厚度。这一版的画布从顶部的 #dfeaf2 极缓地过渡到 #f4f9fc，写作区则是一张半透明的磨砂纸浮在上面。段落之间的关系由留白说明，而不是靠边框。

冰的本质不是透明，而是厚度：一层 1px 的高光、一圈冷色阴影、一点模糊的底色，三者缺一，面板就会塌成一张色卡。

圆角与厚度

  • 大圆角（14–20px）负责“轻”，阴影负责“浮”。
  • 阴影必须是冷色：rgba(14,44,60,.08)，用纯黑会脏。
    • 嵌套一层换空心圆点
    • 再深一层换成实心方点
  • 唯一的高对比留给代码块 —— 独立面板，边框带一点冰蓝。
  1. 先定画布与墨色，再定强调色。
  2. 强调色只出现在三个地方：标题、链接、勾选框。
  3. 暖色只允许出现一次。

1下载并解压

从 Release 下载需要的 CSS 即可：blue-ice.css（浅色）、blue-ice-dark.css（深色）、blue-ice-paper.css（浅色 + 浅灰代码）。

2放进主题文件夹

Typora 菜单：文件 → 偏好设置 → 外观 → 打开主题文件夹。

CSS 必须直接放在该目录下，放进子文件夹不会被识别。三个文件互相独立，只装一个也可以。

3选主题

回到 外观 → 主题，选 Blue Ice、Blue Ice Dark 或 Blue Ice Paper，无需重启。
